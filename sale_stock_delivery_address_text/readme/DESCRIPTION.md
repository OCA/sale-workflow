This module adds a free-text delivery address on the sale order, meant
for sales to generic customers (e.g. a "walk-in customer" contact) where
creating a child delivery contact for every single sale is not wanted.

The address is shown as a highlighted banner on every related transfer
(pick, pack, ship and backorders) and printed on the Delivery Slip and
Picking Operations reports, so the warehouse always sees where the goods
must be delivered.
