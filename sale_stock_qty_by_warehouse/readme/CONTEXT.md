Sales users often need to know where stock is available before confirming a
delivery commitment with a customer.

Odoo already computes product availability, but the standard sale order line
does not show the split by warehouse directly while encoding a quotation.
This module keeps that information close to the order line so the salesperson
can choose the right product quantity or coordinate fulfillment with the
appropriate warehouse.

The module is useful for companies selling from multiple warehouses where the
same product can be available in different locations.
