This module adds an analytic distribution on the sale order that is
applied on all the order lines distributions.

**Table of contents**

.. contents::
   :local:

Usage
=====

- Go to a sale order, **Other Info** tab.
- Set an analytic distribution on the **Analytic Distribution** field
  (next to the tags). It will be propagated to all the order lines that
  don't already have a different distribution set.
- If order lines have different analytic distributions, the field on the
  order is left empty.
- If you need a different distribution on a specific line, set it
  directly on that line.
