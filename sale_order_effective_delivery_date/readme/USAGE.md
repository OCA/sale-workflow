To use the effective delivery date in sales orders:
* Go to **Sales > Orders > Orders**.
* The **Effective Delivery Date** can be displayed in the sales order list. It can be hidden or shown using the optional column settings.
* Use the search bar to search for sales orders by effective delivery date.
* Select **Has effective delivery date** to display orders with an effective delivery date.
* Select **Has no effective delivery date** to display orders without an effective delivery date.
* Use **Effective delivery date: Period** to filter sales orders within a specific date range.
* If required, use **Group By > Effective Delivery Date** to group sales orders by their effective delivery date.

**Note:** The effective delivery date is calculated by standard Odoo based on the first completed customer delivery. 
This module only adds the existing field to the sales order list and search options; it does not change the date calculation.
