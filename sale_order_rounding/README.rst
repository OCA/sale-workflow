This module adds a **Round Up** button to the sale order form. When
pressed, it adds a service line that rounds the order total up to the
nearest integer amount in the order currency.

It is useful to deliver round, cash-friendly totals on quotations and
sales orders without manually computing the adjustment.

   :local:

Usage
=====

To use this module, you need to:

1. Open a quotation or sales order that is not yet confirmed.
2. Click the **Round Up** button in the order header.
3. A *Round Up* line is added so the order total becomes the next
   integer.

Pressing the button again recomputes the adjustment, so it is safe to
use it after changing the order lines. The rounding line is removed and
recreated each time.
