To use this module, you need to:

1.  Open a quotation or sales order that is not yet confirmed.
2.  Click the **Round Up** button in the order header.
3.  A *Round Up* line is added so the order total becomes the next integer.

Pressing the button again recomputes the adjustment, so it is safe to use it
after changing the order lines. The rounding line is removed and recreated
each time.
