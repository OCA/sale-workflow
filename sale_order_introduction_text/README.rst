This module adds an introduction text to Sale Orders, configurable from the Sales settings, and displays it in the Sale Order form, report, and customer portal view.

**Table of contents**

.. contents::
   :local:

Configuration
=============

Go to Sales > Configuration > Settings.
In the Sale Order Introduction Text section, enter the desired text (e.g., a greeting or disclaimer) and save.

Usage
=====

This module is designed to enhance your sales orders by allowing you to add a customizable introduction text that appears on the sale order form, PDF report, and customer portal view.
