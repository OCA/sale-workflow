In some sales flows, fixed-price pricelist rules represent a negotiated or 
controlled price that should be applied as-is. Allowing an additional manual 
discount on the sale order line can bypass that pricing rule and make margins 
or customer agreements harder to control.

This module keeps the standard pricelist behavior, but prevents manual 
discounts on sale order lines when the applied pricelist rule is a 
fixed-price rule. 

Discount-based and formula-based pricelist rules remain unaffected.
