This module provides 4 main features:

1. Version Control - Create new versions when orders are invoiced
2. Order Plan - Split blanket orders into installments
3. Product Costs - Track product budget vs actual
4. Service Costs - Track service budget vs actual

Using Version Control

#. Go to Sales > Orders > Blanket Orders.
#. Select a Blanket Order with all sale orders fully invoiced.
#. Click "Create Version" in the header.
#. (Optional) Enter a Price Adjustment percentage.
#. Click "Create Version".

A new blanket order is created with remaining quantities.

Using Order Plan

#. Go to Sales > Orders > Blanket Orders.
#. Open a confirmed Blanket Order.
#. Click "Create Order Plan" in the header.
#. Configure: Number of Installments, Start Date, Interval.
#. Click "Create Plan".

Use "Create Planned Order" to generate sale orders from installments.

Using Product Costs

#. Open a Blanket Order.
#. Go to the "Product Costs" tab.
#. Add products with target costs.

Using Service Costs

#. Open a Blanket Order.
#. Go to the "Service Costs" tab.
#. Add services with target costs.

Troubleshooting

* "All sale orders must be invoiced" - Invoice all sale orders before creating a version.
* "Number Installment must greater than 1" - Set at least 2 installments for order plans.
