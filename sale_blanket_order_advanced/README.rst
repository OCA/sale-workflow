This module extends the functionality of the standard ``sale_blanket_order``
module with advanced features for managing complex blanket order scenarios.

**Features:**

* **Version Management**: Create and track multiple versions of a blanket order
* **Order Plan Management**: Plan and generate sale orders through installments
* **Cost Tracking**: Monitor product and service costs against targets

**New Models:**

* ``blanket.order.plan`` - Order plan for installment management
* ``blanket.order.product`` - Product cost tracking
* ``blanket.order.service`` - Service cost tracking

**Dependencies:**

* ``sale_blanket_order`` - Base module for blanket orders (OCA)
* ``base_revision`` - For version tracking functionality (OCA)

Configuration
=============

#. Go to Settings > Sales > Blanket Order Advanced.
#. Configure the default features for new Blanket Orders:

   **Enable Version Control** (Default: Enabled):

   - Allows creating new versions when all sale orders are invoiced
   - Useful for annual contracts that need yearly renewals

   **Enable Order Plan** (Default: Disabled):

   - Enables installment/period planning feature
   - Allows splitting blanket orders into scheduled deliveries

   **Enable Product Costs** (Default: Disabled):

   - Adds "Product Costs" tab to track product budget vs actual

   **Enable Service Costs** (Default: Disabled):
   
   - Adds "Service Costs" tab to track service budget vs actual

#. Click "Save" to apply settings.

These settings are defaults for new Blanket Orders. You can also enable/disable
features individually on each Blanket Order form.

Usage
=====

This module provides 4 main features:

1. Version Control - Create new versions when orders are invoiced
2. Order Plan - Split blanket orders into installments
3. Product Costs - Track product budget vs actual
4. Service Costs - Track service budget vs actual

Using Version Control

#. Go to Sales > Orders > Blanket Orders.
#. Select a Blanket Order with all sale orders fully invoiced.
#. Click "Create Version" in the header.
#. (Optional) Enter a Price Adjustment percentage.
#. Click "Create Version".

A new blanket order is created with remaining quantities.

Using Order Plan

#. Go to Sales > Orders > Blanket Orders.
#. Open a confirmed Blanket Order.
#. Click "Create Order Plan" in the header.
#. Configure: Number of Installments, Start Date, Interval.
#. Click "Create Plan".

Use "Create Planned Order" to generate sale orders from installments.

Using Product Costs

#. Open a Blanket Order.
#. Go to the "Product Costs" tab.
#. Add products with target costs.

Using Service Costs

#. Open a Blanket Order.
#. Go to the "Service Costs" tab.
#. Add services with target costs.

Troubleshooting

* "All sale orders must be invoiced" - Invoice all sale orders before creating a version.
* "Number Installment must greater than 1" - Set at least 2 installments for order plans.
