This module adds the product default packaging level on sale order level
(in form and on product configurator as variants can have different
packagings).

.. contents::
   :local:

Use Cases / Context
===================

When we manage different product packaging levels per product, we maybe
want to display the default packaging level on sale order level in order
to help sale people.
