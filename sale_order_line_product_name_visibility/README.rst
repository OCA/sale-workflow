This module allows users to show or hide product name on sale order
line. The ``hide_product_name`` value is copied from Sale Order to
Invoice.

**Table of contents**

.. contents::
   :local:

Usage
=====

- Go to the \**Sale > Orders \*\*, create new o select existing and add
  a new line.
- The product label must be displayed just after the product name.
- Click the toggle button to show or hide the product name.
