This module lets you define a default sale order priority per customer.

It builds on ``sale_order_priority``, which adds a *Priority* (*Normal*
/ *Urgent*) on sale orders and their lines, and computes the order
priority as the maximum priority of its lines.

Configuration
=============

To set the default priority of a customer:

1. Go to *Sales > Orders > Customers* and open a customer.
2. In the *Sales & Purchase* tab, set the *Sale Priority* field.

The field is a commercial field, so a company and its contacts always
share the same value.

Leaving it empty keeps the standard behaviour of
``sale_order_priority``.

Usage
=====

When a sale order is created for a customer having a *Sale Priority*,
the order gets that priority, and ``sale_order_priority`` propagates it
to the order lines.

It is only applied on creation: it is never reapplied afterwards, so you
are free to change the priority of an existing order, and changing the
customer of an existing order leaves its priority untouched.

Known issues / Roadmap
======================

- The customer priority is applied when the order is created, so the
  value is not visible in the quotation form before it is saved.
- The customer priority takes precedence over the priority set on the
  order at creation time: an order created for a customer having a *Sale
  Priority* always gets that priority. Adjust it after the order is
  created if needed.
