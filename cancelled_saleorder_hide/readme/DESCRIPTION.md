This module hides cancelled records from the default list views so that
day-to-day sales and accounting screens are not cluttered with dead data:

- Cancelled sale orders and quotations no longer appear in
  **Sales > Orders > Quotations**.
- Customer invoices and credit notes linked to a cancelled sale order,
  as well as cancelled invoices/credit notes themselves, no longer appear
  in **Accounting > Customer Invoices** and **Accounting > Credit Notes**
  (including when opened from the Accounting Dashboard journal cards).
