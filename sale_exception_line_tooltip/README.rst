This module adds a warning icon and a tooltip directly on sale lines
that have exceptions.

**Table of contents**

.. contents::
   :local:

Configuration
=============

No configuration required.

Usage
=====

1. Open a Sale Order.
2. If any order line has matching exception rules, a warning icon
   appears on that line.
3. Hover the icon to see the names of the exception rules that apply.
4. The icon disappears once the exceptions no longer apply.
