1.  Enable *Discounts* in the Sales settings
2.  Configure a pricelist rule with Discount or Formula Computation and
    the three discounts
3.  Create a sale order and select the configured pricelist
4.  Add a product in the sale order, matching a rule of the configured
    pricelist
5.  If the rule has Discount Computation, check that the three discounts
    defined on the pricelist rule populate the three discounts in the
    sale order line. If the rule has Formula Computation, or *Discounts*
    are not enabled, the three discounts are included in the unit price
    of the sale order line instead, as Odoo does for the standard discount
