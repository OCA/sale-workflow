To configure this module:

1. Go to *Sales > Products > Products* and open a product.
2. Select the sale order types for which the product is allowed in the
   *Sale Order Types* field.
3. For products with variants, sale order types can be configured individually
   on each variant. If no sale order types are configured on a variant, the
   configuration from the product template is used.
4. Go to *Sales > Configuration > Settings* and, under *Quotations & Orders*,
   configure how incompatible products should be handled when changing the sale
   order type:

   * *Prevent Sale Order Type Change*: prevents changing the type if the order
     contains incompatible products.
   * *Remove Invalid Sale Order Lines*: changes the type and removes incompatible
     order lines.
