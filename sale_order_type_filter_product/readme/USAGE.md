To use this module:

1. Create or edit a sales order and select a sale order type.
2. Add a product to the order. Only products allowed for the selected sale
   order type can be selected.
3. For products with variants:

   * When using the product configurator, variants that are not allowed for the
     selected sale order type are shown as unavailable combinations.
   * When selecting a product variant directly from the order line, variants
     that are not allowed for the selected sale order type are not available
     for selection.

4. If the sale order type is changed and the order contains incompatible
   products, the configured company behavior is applied.
