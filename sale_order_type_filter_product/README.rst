This module allows restricting the products available on sales orders
based on the selected sale order type.

**Table of contents**

.. contents::
   :local:

Configuration
=============

To configure this module:

1. Go to *Sales > Products > Products* and open a product.

2. Select the sale order types for which the product is allowed in the
   *Sale Order Types* field.

3. For products with variants, sale order types can be configured
   individually on each variant. If no sale order types are configured
   on a variant, the configuration from the product template is used.

4. Go to *Sales > Configuration > Settings* and, under *Quotations &
   Orders*, configure how incompatible products should be handled when
   changing the sale order type:

   - *Prevent Sale Order Type Change*: prevents changing the type if the
     order contains incompatible products.
   - *Remove Invalid Sale Order Lines*: changes the type and removes
     incompatible order lines.

Usage
=====

To use this module:

1. Create or edit a sales order and select a sale order type.

2. Add a product to the order. Only products allowed for the selected
   sale order type can be selected.

3. For products with variants:

   - When using the product configurator, variants that are not allowed
     for the selected sale order type are shown as unavailable
     combinations.
   - When selecting a product variant directly from the order line,
     variants that are not allowed for the selected sale order type are
     not available for selection.

4. If the sale order type is changed and the order contains incompatible
   products, the configured company behavior is applied.
