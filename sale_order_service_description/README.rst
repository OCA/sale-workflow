Use Cases / Context
===================

Some organizations need to record a textual description of the services
associated with a sales order. Since this information may vary
significantly from one order to another and cannot always be represented
by predefined tags or categories, a dedicated free-text field is
required.

This module adds a translatable service description field to sales
orders and exposes it in search and list views for easier filtering and
reporting.

Usage
=====

To use this module, you need to:

1. Go to the sales order form and add the service description.
