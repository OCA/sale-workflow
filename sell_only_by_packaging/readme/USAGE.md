To use this module, you need to:

1. Go to **Sales > Products > Products** and select a product.
2. Enable **Sell only by packaging** and configure at least one packaging available for sales.
3. Optionally, enable **Force sale quantity** on the packaging to automatically round quantities up to valid packaging multiples.
4. Create a quotation and add the product to a sale order line.
5. Select a packaging or enter a quantity matching an available packaging. When **Force sale quantity** is enabled, subsequent quantity changes are rounded up to a valid multiple of the selected packaging.
