To use this module:

1. Go to Sales > Orders and create or edit a sale order
2. The "Only Customer Addresses" checkbox appears next to the customer field
3. When checked (default), delivery and invoice address dropdowns only show addresses belonging to the customer's commercial company
4. Uncheck the box to see all available addresses
5. Address fields are preserved when toggling the restriction

The checkbox is only visible when a customer is selected.
