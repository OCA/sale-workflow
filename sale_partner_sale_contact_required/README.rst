This module makes the **Sale Contact** field added by
``sale_partner_sale_contact`` mandatory on quotations and sale orders.

Install it when every deal must be linked to a named commercial contact
person of the customer, so that no quotation or order can be saved
without one.

Only ``sale.order`` is affected: invoices and vendor bills
(``account.move``) keep the sale contact optional, since the contact is
normally propagated from the originating sale order.

Usage
=====

Once installed, the **Sale Contact** field is required on every
quotation and sale order:

1. Go to *Sales > Orders > Quotations*
2. Create a quotation and select a customer
3. The **Sale Contact** field is marked as required and the record
   cannot be saved until a contact person of that customer is selected

**Note**: customers without any child contact (typically B2C
individuals) cannot be used on a sale order while this module is
installed. Create a contact person under the customer first, or do not
install this module.
