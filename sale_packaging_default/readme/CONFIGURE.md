To configure this module, you need to:

1.  Go to *Sales \> Configuration \> Settings*.
2.  Under *Product Catalog*, enable *Product Packagings*.


If you want to make packaging mandatory if the product has available packagings for Sales:

1.  Go to *Settings > Technical > Parameters > System parameters*.
2.  Create `sale_packaging_default.packaging_required` parameter with value `1`.
