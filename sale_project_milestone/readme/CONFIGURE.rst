1. Enable Project Milestones feature:

   * Go to Settings > Project
   * Enable "Project Milestones"

2. Create or configure a service product:

   * Go to Sales > Products > Products
   * Create or edit a service product
   * Set **Create on Order** to "Project & Milestone"
   * Optionally configure a **Project Template** for consistent project creation
   * Optionally set **Service Invoicing Policy** to "Based on Milestones"
