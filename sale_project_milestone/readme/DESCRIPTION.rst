This module adds the ability to create projects with milestones from sale order lines, offering flexible project management.

**Features:**

* New service tracking option: **"Project & Milestone"**
* Create new projects with milestones (supports project templates)
* Select existing projects to add milestones
* Link existing milestones to sale order lines (even after confirmation)
* Automatic analytic line registration on the project's analytic account
* Support for milestone-based invoicing (delivered_milestones service policy)
* Compatible with standard project creation workflows
