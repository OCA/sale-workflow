This module extends the functionality of procurements to allow you to
create different procurements for free products (100% discount).

When this module is installed, each sale order you confirm will generate
one delivery order for products with 100% discount.

You can customize procurement end text by creating parameter
``sale_delivery_split_free_products.procurement_discount_text``. By
default will be "FREE".

Example: SO0026/FREE

Use Cases / Context
===================

This module was developed because sometimes we don't want our stock
movements to be merged if free products are sold in separate order
lines.

- Sale free products that must be invoiced separatelly (for example, get
  2 + 1 free) on different lines.
- Use products with Invoicing Policy: Delivered Quantities

With this module, a new procurement will be created for products with
100% discount.

Usage
=====

To use this module, you need to have activated sales module:

1. Activate sale module.
2. Create and confirm a sale with 2 lines: One with discount and one
   without discount with the same product.
3. Confirm the sale.
4. Check 2 procurements are created: One for the normal product and one
   for the free product.
5. Modify quantity order lines and check propagation to the pickings.
