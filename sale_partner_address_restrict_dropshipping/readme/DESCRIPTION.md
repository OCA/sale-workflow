When using the Sale Partner Address Restrict module, you are forced to use
invoice and delivery addresses related to the main customer.

In dropshipping scenarios, the delivery address represents a final end customer
that is not part of the main customer, but it is still useful to have the
relation in the system so that you know which dropship addresses have been
created for each of your main customer.

With this module you can flag the dropship delivery addresses to ensure that
the main customer name is not displayed for them.
